\section{Technology Stack}
\label{sec:technology}

\subsection{Core Technologies}
\label{subsec:core_tech}

\begin{itemize}
    \item \textbf{Node.js} --- Runtime for all microservices and adapters.
    \item \textbf{RabbitMQ} --- Message broker providing the asynchronous pub-sub backbone via a topic exchange.
    \item \textbf{PostgreSQL} --- Relational database used by the Auth, CMS, and Notification services for persistent state.
    \item \textbf{Docker} --- Each service is packaged and run as an individual container.
    \item \textbf{Docker Compose} --- Orchestrates the full multi-container platform for the prototype deployment.
\end{itemize}

\subsection{Library Dependencies}
\label{subsec:lib_deps}

\begin{itemize}
    \item \textbf{Express.js} --- HTTP server framework used by services that expose REST endpoints.
    \item \textbf{http-proxy} --- Lightweight reverse-proxy library powering the API Gateway.
    \item \textbf{jsonwebtoken} --- JWT signing and verification for authentication.
    \item \textbf{bcryptjs} --- Adaptive password hashing used by the Auth Service.
    \item \textbf{amqplib} --- AMQP client for all RabbitMQ publish and subscribe interactions.
    \item \textbf{ws} --- WebSocket server library used by the Notification Service.
    \item \textbf{soap} --- SOAP client used by the CMS Adapter to communicate with the legacy CMS.
    \item \textbf{axios} --- HTTP client used by the ROS and WMS adapters.
    \item \textbf{pg} --- PostgreSQL client for Node.js, used for all database queries.
\end{itemize}
