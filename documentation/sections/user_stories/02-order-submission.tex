\subsubsection{User Story 2: Order Submission}

% TODO: Add content

\paragraph{Description}
As a client, I want to submit a new delivery order so that my package can be picked up and delivered to the destination.

\paragraph{Actors}
\begin{itemize}
    \item Client
    \item API Gateway
    \item Order Service
    \item WMS Service
\end{itemize}

\paragraph{Sequence Diagram}

\paragraph{Business Details}
The order workflow is divided into three stages.
First, the client browses inventory; the system queries the WMS and returns the current stock list in real time via WebSocket.
Second, the client creates an order with a chosen item list; the system registers the order in the CMS legacy system and creates a payment intent, returning a clientSecret to the client via WebSocket.
Third, the client confirms the order using the clientSecret as the payment token; the system updates the CMS order status, reserves stock in WMS, and charges payment in sequence.
If all steps succeed the order is marked pending delivery the client is notified; on payment decline or insufficient stock, compensating events roll back the reservation and the client is notified of the specific failure.
