\section{Proposed Architecture}

The SwiftTrack platform is implemented as an event-driven microservices architecture. These services communicate asynchronously through the message broker. All external traffic enters through an API Gateway and no internal service is reachable from outside.

HTTP requests travel from the client through the API Gateway which then routes to the services, which returns an immediate acknowledgement of the idemportency key. Asynchronous AMQP messages travel between these services and adapters via the message broker, with each adapter performing the necessary protocol translation before calling its legacy system. After the Saga is completed, Real-time WebSocket frames travel from the Notify Service, through the API Gateway WebSocket proxy, to the connected client or driver.
