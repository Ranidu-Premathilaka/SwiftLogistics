## Diagram Format

All diagrams should be created in one of the following formats:
- **PDF** (preferred for vector graphics)
- **PNG** (for screenshots and raster images)

## Tools for Creating Diagrams

Recommended tools:
- **draw.io / diagrams.net** - Free online/desktop diagramming tool
- **Lucidchart** - Professional diagramming tool
- **PlantUML** - Text-based UML diagrams
- **Microsoft Visio** - Professional diagramming software
- **Inkscape** - Free vector graphics editor
- **Adobe Illustrator** - Professional vector graphics editor

## Diagram Guidelines

1. **Consistency**: Use consistent colors, shapes, and notation across all diagrams
2. **Clarity**: Ensure labels and text are readable
3. **Professional**: Follow standard notation (UML, C4 model, etc.)
4. **Resolution**: Export at high resolution (300 DPI minimum for PDF)
5. **Color**: Use color-blind friendly palettes
6. **Legend**: Include legends where necessary
